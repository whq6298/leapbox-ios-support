乐宝箱手机版隐私政策

更新日期 2026 年 11 月 12 日

本机保存的信息

乐宝箱手机版在手机上保存外观偏好、手动连接地址、扫描端口、车辆备注、近期诊断日志及待查询的安装任务。导入的 APK 会复制到应用专属目录，下次导入时替换。你可以在关于页面清理所选安装包，删除 App 可移除应用目录内的数据。

调试身份

ADB 的 RSA 私钥由 Apple 系统钥匙串在本机保存，用于向目标车机证明调试身份。车机接收公钥并由你确认调试授权。你可以在车机开发者设置中撤销调试授权。钥匙串中的调试身份可能在重新安装 App 后继续存在。

局域网连接

局域网访问用于你发起的设备发现、连接、信息读取和安装包传输。扫描会探测所选网段的指定端口。连接时读取车机型号、系统版本、当前 Android 用户及设备标识，用于显示信息和核对目标。APK 和必要的安装组件经已授权的 ADB 连接传到你指定的目标设备。

统计与分享

当前 iOS 版本的核心功能在本地运行，自动统计、广告及跟踪 SDK 的数量为零。车辆地址、备注、APK 内容及安装日志保存在本机或你指定的目标设备。

主动分享日志时，系统会把日志交给你选择的分享目标。日志可能包含设备地址、调试指纹和安装信息，请在分享前检查内容。

邮件支持与网站访问

你可以自愿发送邮件至 344244755@qq.com 寻求支持。邮件地址、正文及你主动提供的附件会用于处理你的请求，请自行决定分享哪些信息。

访问本网站时，浏览器会向网站发出常规网络请求，其中可能包含 IP 地址、访问时间、请求路径及浏览器信息等网络请求信息。

本页面由 GitHub Pages 托管。访问页面时，GitHub 会出于安全目的记录并保存访问者的 IP 地址。详情见 GitHub 隐私声明。

权限管理

你可以在 iOS 设置的隐私与安全性中管理本地网络权限。撤销权限后，设备扫描与连接可能无法完成。
